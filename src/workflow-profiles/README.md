# Bundled workflow profiles

This directory is an offline, reviewed adaptation of selected BMAD-METHOD and Spec Kit material. Uroboros loads only the six `adapted/` sections after validating the manifest and every bundled byte; the `upstream/` files are preserved reference data and are never evaluated as instructions, scripts, hooks, or configuration.

The manifest pins BMAD-METHOD at `abe4eb1bce919c9d22cd18b3519353d5824c4b75` and Spec Kit at `0c8e31ff0a98c362696c2edb6a1bb25a37f68544`. It records the original repository-relative paths, installed local paths, and SHA-256 values for all selected sources, notices, and adapted runtime sections. Both projects' MIT notices are retained; BMAD's trademark notice is retained and its guidance remains available at [BMAD trademark guidelines](https://github.com/bmad-code-org/BMAD-METHOD/blob/abe4eb1bce919c9d22cd18b3519353d5824c4b75/TRADEMARK.md).

The adaptations are intentionally bounded. They do not claim endorsement by BMAD, do not rename Uroboros as a BMAD product, and do not import upstream personas, installs, dependencies, menus, hooks, task counts, hierarchy gates, approval seats, optional-test defaults, finding caps, ignore-file edits, or checkbox-only completion. User requirements, project constraints, permissions, reviewer authority, and evidence rules take precedence.

Captured bindings are self-validating historical records: a future installed default is not consulted to validate a saved capture. Updating a profile requires a reviewed change to its source data, adaptation, manifest hashes, and binding digest.
