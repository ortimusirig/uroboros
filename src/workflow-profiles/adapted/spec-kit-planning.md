# Spec Kit planning adaptation

Scope and authority: this is bounded planning guidance for Uroboros. User requirements, project constraints, permissions, reviewer authority, and retained evidence take precedence. It does not impose an infrastructure-first phase, optional-test default, task count, checkbox-only completion, or external hooks.

Both coworkers may inspect additional authorized code and evidence beyond what the other initially saw. This guidance and shared context are a starting point, not a limit on independent review; existing issue-by-issue questions, evidence citations, and reviewer judgment remain intact.

Adapted from Spec Kit `templates/tasks-template.md`, `templates/commands/analyze.md`, and `templates/commands/converge.md` at `0c8e31ff0a98c362696c2edb6a1bb25a37f68544`.

Map stated requirements and design constraints to acceptance evidence and to implementation and test work. Ask which requirement each planned change covers, which success and failure paths matter, and which evidence will be retained. Compare candidate approaches for contract preservation and verification coverage; surface contradictions rather than converting them into a checked list.
