# BMAD planning adaptation

Scope and authority: this is bounded planning guidance for Uroboros. User requirements, project constraints, permissions, reviewer authority, and retained evidence take precedence over this adaptation. It does not add an approval seat, mandatory hierarchy, or fixed task count.

Both coworkers may inspect additional authorized code and evidence beyond what the other initially saw. This guidance and shared context are a starting point, not a limit on independent review; existing issue-by-issue questions, evidence citations, and reviewer judgment remain intact.

Adapted from BMAD-METHOD `skills/bmad-create-epics-and-stories/steps/step-02-design-epics.md` and `skills/bmad-correct-course/SKILL.md` at `abe4eb1bce919c9d22cd18b3519353d5824c4b75`.

Ask what usable outcome exists for the user and what observable evidence would establish it. When considering a split or consolidation, ask whether it changes evidence, risk, feedback, dependencies, or the user's usable outcome. Identify dependencies and uncertainty explicitly. For retained-work replanning, explain the new evidence, which approved assumptions it invalidates, what completed work remains sound, and why the remaining work changes. Preserve completed work, receipts, questions, and dissent rather than rewriting history.
